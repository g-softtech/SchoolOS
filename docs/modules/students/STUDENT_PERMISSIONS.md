# Student Module Permissions

| Permission String | Description | Default Roles |
| :--- | :--- | :--- |
| `students.read` | View basic student and guardian data | Admin, Staff, Teacher |
| `students.profile.update` | Edit bio, demographics, addresses | Admin, Registrar |
| `students.status.update` | Transition student lifecycle states | Admin, Registrar |
| `students.guardians.manage` | Link/unlink guardians and contacts | Admin, Registrar |
| `students.strategy.manage` | Configure numbering schemas | Admin |
