# Website Builder Widgets

The Website module exposes the following UI Widgets to the unified Tenant Dashboard (`apps/tenant-dashboard`).

## 1. "Website Quick Stats" Widget
* **Size:** Small (1x1)
* **Data:** Total Page Views (last 7 days), Active Published Pages, Storage Used (MB).
* **Deep Link:** Directs to the CMS overview.

## 2. "Drafts Pending Approval" Widget
* **Size:** Medium (2x1)
* **Data:** List of pages in `DRAFT` status sorted by oldest modified date.
* **Deep Link:** Directs to the Page Editor.

## 3. "Recent Media Uploads" Widget
* **Size:** Large (2x2)
* **Data:** Grid thumbnails of the 6 most recently uploaded images to the Asset library.
* **Deep Link:** Directs to the Media Manager.
